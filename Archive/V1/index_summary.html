Main file: index.html (619 lines, single self-contained file: inline CSS + vanilla JS, no dependencies). Problem class: Coins 1 — make amount A from exactly N US coins. Companion: schematic.md.

3. Key ideas

One source of truth
The combo {P,N,D,Q,H,S} drives everything. Table-top coin objects are re-synced to it (syncTable), so editing a number, trading, or dragging all agree.
Solver
sols() recurses from the biggest coin down, pruning when remaining cents can't fit remaining coins (between coins × smallest and coins × next-largest). Capped at 3000 results.
Graph of all solutions
Two chosen coins are axes. The other two (dep) are solved from the count and value equations, so each dot is a full answer. Extra coin types beyond four are fixed.
Sort animation
Coins position with CSS transform (not an SVG attribute), so adding class anim gives a smooth transition; after 750ms the table re-renders in its final layout.

5. Known limits

  • Touch input and very large sorts are untested.
  • No external CSS/JS files: everything is inline in index.html.
  • Coins 2–5 tabs (.ptabs) are disabled placeholders.
  • With 5–6 coin types the graph holds the extra coins fixed instead of showing every solution.
